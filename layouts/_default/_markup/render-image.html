{{- /* ========================================================================== Drawing Set — image render hook. Derived from Blowfish v2.105.0 layouts/_default/_markup/render-image.html. PRESERVED from upstream: page-resource / remote / SVG branching, responsive srcset, lazy + async + fetchpriority, medium-zoom (data-zoom-src), and .Attributes passthrough. [DWG] changes, each with a reason: 1. Animated formats (gif, apng) bypass .Resize entirely. Hugo's image pipeline decodes only the FIRST FRAME, so resizing silently kills the animation -- which would break the SDKMAN tab-completion GIF. 2. Corrected `sizes`. Upstream says 65vw for mobile, but the body is px-6 (1.5rem each side), so at 360px the column is 312px = 86.7vw. The browser was under-selecting and plates rendered soft. 3. `class` is MERGED with author attributes rather than emitted twice (upstream's `range .Attributes` would produce a duplicate attribute). 4. A figure becomes a PLATE (framed, numbered) iff it has a markdown title: ![alt](src "caption"). Untitled images stay plain. This matches the drawing-set convention that only figures are numbered, and it keeps screenshots/logos/GIFs out of the plate sequence. 5. warnf when a non-remote image resolves to nothing -- resources.Get reads assets/ ONLY, never static/, so this catches any image left behind by the page-bundle migration instead of failing silently. Deliberately NOT added: resources.GetRemote localisation of remote images. No remote images remain in the content, and making the build depend on a third party is a real risk -- the post's old SDKMAN SVG now 404s. All visual styling lives in assets/css/custom.css. Plate numbering is a CSS counter, not Hugo state: .Content is evaluated more than once per page and out of document order (index.json, rss.xml, .Summary, .TableOfContents), so a .Store/.Scratch counter drifts. ========================================================================== */ -}} {{- define "RenderImageSimple" -}} {{- $imgObj := .imgObj -}} {{- $src := .src -}} {{- $alt := .alt -}} {{- $extra := .extra | default "" -}} {{- end -}} {{- define "RenderImageResponsive" -}} {{- /* sizes: below md the plate fills the padded column (~87vw at 360px); at md+ it is bounded by the prose measure (max-w-prose, 65ch). */ -}} {{- $imgObj := .imgObj -}} {{- $alt := .alt -}} {{- $w := $imgObj.Width -}} {{- $img640 := $imgObj -}} {{- $img960 := $imgObj -}} {{- $img1440 := $imgObj -}} {{- if gt $w 640 }}{{ $img640 = $imgObj.Resize "640x" }}{{ end -}} {{- if gt $w 960 }}{{ $img960 = $imgObj.Resize "960x" }}{{ end -}} {{- if gt $w 1440 }}{{ $img1440 = $imgObj.Resize "1440x" }}{{ end -}} {{- $srcset := printf "%s 640w, %s 960w, %s 1440w" $img640.RelPermalink $img960.RelPermalink $img1440.RelPermalink -}} {{- end -}} {{- $disableOpt := .Page.Site.Params.disableImageOptimizationMD | default false -}} {{- $urlStr := .Destination | safeURL -}} {{- $url := urls.Parse $urlStr -}} {{- $altText := .Text -}} {{- $caption := .Title -}} {{- $isRemote := findRE "^(https?|data)" $url.Scheme -}} {{- $resource := "" -}} {{- if not $isRemote -}} {{- $resource = or ($.Page.Resources.GetMatch $urlStr) (resources.Get $urlStr) -}} {{- if not $resource -}} {{- warnf "[DWG] image %q not found as a page resource or under assets/ -- rendering unoptimised (page: %s).
